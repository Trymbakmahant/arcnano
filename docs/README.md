# ArcNano Documentation Web App (`docs.arcnano.xyz`)

> **Official developer documentation for ArcNano — Shielded Zero-Knowledge Nanopayments on Arc.**
> Designed with GitHub Docs aesthetics, Primer typography, responsive sidebar navigation, and search.

---

## 🚀 Running Locally

```bash
cd docs
pnpm install
pnpm dev --port 3002
```

Open [http://localhost:3002](http://localhost:3002) in your browser.

---

## 🌐 Subdomain Deployment (`docs.arcnano.xyz`)

This Next.js app is completely standalone and ready to deploy to Vercel, Cloudflare Pages, or AWS:
- **Root Directory:** \`docs\`
- **Build Command:** \`pnpm build\`
- **Output Directory:** \`.next\`
- **Custom Domain:** \`docs.arcnano.xyz\`
