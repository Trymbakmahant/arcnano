# ArcNano Verdict ⚖️

> **Minimalist Deterministic Cryptographic Reasoner**

ArcNano Verdict is a standalone, ultra-minimalist decision and evaluation app designed for autonomous AI agents, protocol researchers, and developers on the Arc Network.

It provides immediate, binary **YES** or **NO** determinations with cryptographic reasoning, strictly eliminating filler text and marketing jargon.

---

## ⚡ Quick Start

```bash
cd verdict
pnpm install
pnpm dev
```

The app will run locally on `http://localhost:3001`.

---

## 🛠 Features

- **Binary Precision**: Bold, high-contrast `YES` / `NO` determinations.
- **Minimalist Aesthetic**: Zero text waste; only essential cryptographic proofs, confidence scores, and protocol anchors.
- **Shared Arc Theme**: Matches the institutional CAD grid and color system of ArcNano (`#FAFAFA` surface, `#090A0F` dark mode, Emerald for affirmations, Rose for negative constraints).
- **Fast Evaluation**: Instant offline heuristic and deterministic circuit rules with optional GLM-4 inference.
- **Preset Scenarios**: 1-click evaluation of critical questions regarding `msg.sender` leakage, $0.00 gas sponsorship, OFAC compliance, sub-10ms latency, and double-spend protection.
